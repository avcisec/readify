# Architecture decisions

ADRs record decisions that are costly to reverse or constrain future work. Status values are `Proposed`, `Accepted`, `Superseded`, or `Rejected`. Never rewrite the rationale of an accepted ADR; add a superseding ADR and link both.

New ADRs should state context, choice, reasons, alternatives, tradeoffs, migration difficulty, and consequences.
